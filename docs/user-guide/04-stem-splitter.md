# 4. Stem Splitter

[← Library and References](03-library.md) · [Contents](README.md) · [Next: Effects →](05-effects.md)

## 4.1 Choose a track

Open **Stem Splitter**, then choose a source track or load one from Samples. The **Split track** action starts processing only after you press it; merely selecting a sample does not split it.

The default Demucs model is `htdemucs`. It produces four stems:

- vocals
- drums
- bass
- other

## 4.2 Run a split

1. Choose the source track.
2. Press **Split track**.
3. Wait for the progress display to finish.
4. Preview each generated stem with its transport controls.

The first split may download the model and can take several minutes. Generated stems are held temporarily until you export them.

## 4.3 Export stems

Each stem can be saved individually. To export all stems together, choose one of the folder actions:

- **Named folder** creates a new destination folder.
- **Existing folder** writes into a folder you choose.

Exported WAV files can then be found in the Library view if they were saved inside StemKart's managed library.
